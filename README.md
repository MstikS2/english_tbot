# The English teacher telegram bot *[under development]*
> By [MstikS2](https://github.com/MstikS2 'GitHub')

The bot is developed using pyTelegramBotAPI with SQLAlchemy and SQLite (temporary)  
for DB.

### Features:

- The teacher can manage student's profiles;
- The teacher can set up lessons for students;
- The teacher can add words to dictionary;
- The teacher can make tasks to dictionary;
- The teacher can monitor student's progress;
- The students can manage their own profiles;
- The students can learn the english words by choosing correct translation  
using telegram buttons;
- The students can study by completing fill-in tasks;
- Both teacher and students can get notifications about lessons.
